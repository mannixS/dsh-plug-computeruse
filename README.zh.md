# Cua 电脑控制 · DeepSeek Harness 插件

[English](README.md) · **简体中文**

让你的 DeepSeek Harness Agent 真正会用电脑——在 Windows、macOS 和 Linux 上点击、输入、看懂屏幕。

Cua Driver 的核心组件随插件一起安装。**不需要另装驱动、不需要配 MCP、不需要设 PATH、也没有要单独下载的东西。** 装上插件，Agent 就能操作桌面。

```
"打开计算器，算一下 847 × 392"
"在下载文件夹里找到那张发票 PDF，把总额读给我"
"按我上一封邮件里的信息把这个表单填好"
```

---

## 为什么用这个插件

常见的桌面自动化方案，要先装驱动、起后台服务、再接一层传输协议，Agent 才能动一下。这个插件只有一个步骤：装插件。

| | |
| --- | --- |
| **开箱即用** | Cua Driver SDK 和对应平台的原生二进制随插件一起装好，不用另外下载或配置。 |
| **锁定单个应用** | 指定一个应用后，Agent 在物理上就无法截取或操作其他窗口。这层限制由插件强制执行，不靠模型自觉。 |
| **该问的才问** | 点击、输入这类操作可以先征求你同意；只是看屏幕不会打扰你。 |
| **不留垃圾** | 截图定时清理，并在对话结束时整体清空。 |
| **看得见它在做什么** | 按会话显示的焦点光标，标出 Agent 即将操作的区域。 |
| **图形界面就能配** | 在「设置 → Cua 电脑控制」里有完整设置页，改完立即生效。 |

## 安装

**从 npm 安装**

在 DeepSeek Harness 左侧打开 **插件** → **添加插件** → 输入：

```
dsh-plug-computeruse
```

**从本地目录或 GitHub 安装**

同样在 **添加插件** 里，填本目录的绝对路径或仓库地址即可。

装好后**新开一个会话**，工具才会注册。首次安装会拉取 Cua Driver SDK 与对应平台的二进制（约 28 MB）。

> 需要 DeepSeek Harness `>=0.2.2-rc.3 <0.3.0`，Node 20 以上。

## 快速上手

直接用自然语言说就行，Agent 会自己选工具和参数：

```
截个计算器的图，告诉我屏幕上显示什么。
```

也可以显式调用：

```json
{
  "action": "call",
  "name": "get_window_state",
  "arguments": {
    "include_accessibility_tree": true,
    "include_screenshot": true,
    "session": "my-task"
  }
}
```

推荐的循环是**看 → 做 → 再看**：先读一次最新状态，据此操作，然后重新确认结果。不要复用旧快照里的元素标识；工具返回成功只代表「动作已发出」，不代表「界面已改变」。

## 设置

**设置 → Cua 电脑控制**，和 Trae、WorkBuddy 等第三方插件在同一处。

| 设置项 | 默认 | 作用 |
| --- | --- | --- |
| 控制范围 | 整个桌面 | 选「仅一个应用」后，每次调用都固定到该应用 |
| 固定应用 | — | 可执行文件名（如 `CalculatorApp.exe`）或进程号 |
| 操作前确认 | 仅修改类操作 | 可选「所有操作」「仅修改类操作」「从不确认」 |
| 显示焦点光标 | 开 | 标出 Agent 即将操作的区域 |
| 截图保留时间 | 900 秒 | 落盘截图到期删除，对话结束也会清空 |
| 截图长边上限 | 驱动默认 | 图片越小，消耗的 token 越少 |
| 调用超时 | 120000 毫秒 | 单次驱动调用的上限 |

点保存**立即生效**，不用重启，也不用新开会话。

> `allowTools` 和 `session` 只能改配置文件；上表各项都在界面里。

## 锁定单个应用

这是让自动化可以放心长期跑着的那项能力。

```yaml
scope: window
app:
  name: WXWork.exe
```

开启 `scope: window` 后：

- 整屏截图被**直接拒绝**，报错会提示 Agent 改用 `get_window_state`。
- 未指定窗口的调用会自动绑定到固定应用的窗口。
- 属于其他应用的窗口会被**拒绝**，并说明当前固定的是哪个应用。
- 按应用名固定时，应用重启换了进程号仍在范围内。

这层拒绝是代码强制的，不是请模型自觉遵守：

```
dsh-cua: scope is "window", so get_desktop_state is not available.
Use get_window_state on the pinned app instead, or set scope to "desktop" in the plugin configuration.
```

## 截图是怎么处理的

截图正常情况下作为附件直接交给模型，不落磁盘。只有当模型不支持图片、或附件服务不可用时，才会写到 `<会话目录>/.dsh-cua/`。这些文件会：

1. **定时清理**：默认每 60 秒扫一次，删掉超过保留时间的文件。
2. **每次调用后清理**：每次调用结束立即清扫一次。
3. **对话结束时清空**：整个目录删掉。

把保留时间设为 `0`，就只在当前这一轮内保留。

## 系统要求

驱动是内置的，但操作系统仍有最终决定权：

- **Windows**：需要已登录的交互式桌面会话。
- **macOS**：需要给运行 DeepSeek Harness 的应用授予「辅助功能」和「屏幕录制」权限。macOS 上驱动会优先使用它自带的签名辅助程序（随插件安装），这样系统才能正确归属这些权限；不可用时回退到进程内运行时。
- **Linux**：需要 X11 或 XWayland。

## 需要知道的几点

- **悬窗和强制停止还没做。** 当前靠审批、单应用范围和禁用插件来控制。带强制停止的悬浮窗在计划中。
- **截图和界面文字会发给你选的模型。** 请确认所用服务商的隐私条款你能接受。
- **「动作已发出」不等于「界面已改变」。** 操作后应重新读取或用 `verify_state` 确认。超时后先查状态再重试，不要盲目重复。
- **部分应用无法固定**：全屏独占或无窗口的应用没法限定范围。
- **`get_desktop_state` 不接受 `include_screenshot`**：它总是截图，只能用 `max_image_dimension` / `screenshot_out_file` 调节。
- **`get_window_state` 的无障碍遍历默认 1000 毫秒预算**，超出会返回 `degraded: true` 和部分树。可调高 `timeout_ms` 或限制 `max_elements`。

## 开发

```sh
pnpm run check     # 语法检查所有模块
pnpm test          # 62 项单元测试
```

真实桌面联调（只做只读调用和计算器操作，不会往聊天窗口里输入任何内容）：

```powershell
$env:ELECTRON_RUN_AS_NODE='1'; & $env:DSH_NODE_EXECUTABLE test/integration-live.mjs
```

联调覆盖：`desktop` 范围允许整屏、`window` 范围拒绝整屏、跨应用被拒、修改类操作返回 `ask` 而只读放行、回合结束后截图目录为空。
